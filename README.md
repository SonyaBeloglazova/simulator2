# Симулятор муравья

Десктопное приложение с графическим интерфейсом, которое моделирует поведение виртуального муравья на двумерном поле

---

## Описание и возможности

Виртуальный муравей перемещается по двумерной сетке из белых и чёрных клеток, перекрашивает их и меняет направление движения по заданным пользователем правилам:

* **Настройка игрового поля:** выбор ширины и высоты сетки (от 5 до 50 клеток)
* **Гибкие правила поведения:** настройка списка действий отдельно для белой и чёрной клеток[span_3](start_span)[span_3](end_span):
  * Повернуть направо[span_4](start_span)[span_4](end_span)
  * Повернуть налево[span_5](start_span)[span_5](end_span)
  * Идти прямо[span_6](start_span)[span_6](end_span)
  * Перекрасить клетку[span_7](start_span)[span_7](end_span)
* **Стартовая позиция:** ручной ввод координат X и Y или случайная генерация.
* **Управление симуляцией:** кнопки «Сгенерировать», «Запустить» и «Пауза»[span_8](start_span)[span_8](end_span).
* **Плавная анимация:** визуализация перемещения муравья с помощью `DispatcherTimer`.

# Симулятор муравья

Виртуальный муравей ходит по двумерному полю из черных и белых клеток, перекрашивает их и меняет направление по правилам, которые задает пользователь

## Возможности

- Поле произвольного размера (от 5×5 до 50×50)
- Случайная генерация черных/белых клеток
- Задание начальной позиции муравья (или случайная)
- Настройка последовательности действий отдельно для белой и черной клетки:
  - Повернуть направо
  - Повернуть налево
  - Идти прямо
  - Перекрасить клетку
- Кнопки: **Сгенерировать**, **Запустить**, **Пауза**
- Анимация перемещения стрелки (муравья)
- Тороидальное поле (выход с края — вход с противоположной стороны)

## Как запустить

- Скачайте проект
  - Архивом: нажмите зеленую кнопку <> Code вверху страницы → Download ZIP и распакуйте архив
  - Через Git: откройте терминал в нужной папке и выполните: 
   
```bash
git clone https://github.com/SonyaBeloglazova/simulator2.git
```
- Запустите программу
  - Через Visual Studio: откройте файл WpfApp1.csproj и нажмите F5
  - Через терминал (PowerShell / cmd): перейдите в папку с проектом и запустите его:
```bash
cd simulator2/WpfApp1
dotnet run
```

## Как пользоваться

1. Укажите ширину и высоту поля (5–50)
2. Укажите стартовые координаты X и Y. Если оставить пустым — позиция будет случайной
3. Настройте правила для белой и чёрной клетки:
   - Выберите действие в выпадающем списке
   - Нажмите «Добавить»
   - Можно удалить выбранное действие кнопкой «Удалить»
   - Порядок действий важен — они выполняются сверху вниз
4. Нажмите **Сгенерировать** — появится поле и красная стрелка (муравей)
5. Нажмите **Запустить** — симуляция пойдёт с анимацией
6. **Пауза** останавливает выполнение

По умолчанию уже заданы правила муравья:
- Белая: повернуть направо, перекрасить
- Чёрная: повернуть налево, перекрасить, идти прямо

Можно оставить эти правила, можно задать свои
